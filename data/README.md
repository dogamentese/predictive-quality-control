## How to get the data

Download the SECOM dataset from the UCI Machine Learning Repository:

<https://archive.ics.uci.edu/dataset/179/secom>

Place the downloaded files in `data/raw/`.

## About the dataset

SECOM is a semiconductor manufacturing process dataset: 1567 examples, each with
590 sensor/process measurements, plus a pass/fail label and a timestamp per
example.
